# Student Development Checklist

Use this during development. Update your single Master Project Showcase PPT with evidence as your project progresses.

## Setup
- [ ] Keep `products.csv` and `sales_transactions.csv` in the same folder as your Python file.
- [ ] Review the CSV column names before coding.
- [ ] Rename/copy `starter_code.py` to your working Python file if required.

## Build
- [ ] Load product data.
- [ ] Display the main menu.
- [ ] View products.
- [ ] Create a multi-item customer bill.
- [ ] Validate Product ID.
- [ ] Validate quantity.
- [ ] Check stock availability.
- [ ] Calculate item totals and final bill.
- [ ] Update stock only after a successful sale.
- [ ] Save updated inventory to `products.csv`.
- [ ] Append successful transaction lines to `sales_transactions.csv`.
- [ ] Display low-stock products.
- [ ] Display basic sales summary.
- [ ] Handle invalid menu/input cases.

## Test
- [ ] Test at least one successful transaction.
- [ ] Test invalid Product ID.
- [ ] Test zero/negative/non-numeric quantity.
- [ ] Test insufficient stock.
- [ ] Test an out-of-stock product.
- [ ] Confirm inventory persists after restart.
- [ ] Confirm transaction history is appended, not overwritten.

## Showcase PPT
- [ ] Add final workflow only after the application matches it.
- [ ] Add screenshots of working features.
- [ ] Add representative test evidence.
- [ ] Explain Python concepts used.
- [ ] Do not claim features you did not implement.
